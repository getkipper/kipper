# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1. By taking part in this project (issues, pull requests, discussions) you agree to uphold it.

The short version: be respectful, assume good intent, and help keep this a welcoming place for people of every background and experience level. Many contributors are new to Go or Kubernetes, so patience and constructive feedback matter.

## Reporting

If you see behaviour that breaks the Code of Conduct, report it privately to the maintainers at conduct@getkipper.com. Reports are handled confidentially. The maintainers will review every report and respond as the Contributor Covenant describes, and they will respect the privacy and safety of whoever reports an incident.

The full text of the Contributor Covenant 2.1, including the enforcement guidelines, is available at the link above.
